# SmartCampus AI — College Department Attendance & Leave Intelligence System

A production-ready, enterprise-grade **College Department Student Attendance and Leave Intelligence System** built with **React 18, TypeScript, Tailwind CSS**, and inspired by academic accreditation standards (NAAC / NBA / NIRF).

---

## 🌟 Key Features

1. **Dual-HOD Command Center**:
   - Cross-year attendance pulse across **1st Year, 2nd Year, 3rd Year, and 4th Year**.
   - Faculty 8-period compliance ticker.
   - Critical shortage & detention risk radar (<75%) with **Predictive Recovery Simulator**.
   - 1-Click **Signed NAAC/NBA Register Exporter**.

2. **8-Period Smart Attendance Grid**:
   - 1-Click "Mark All Present" with instant tap-to-toggle for absentees.
   - **Auto-Lock**: Students with approved Prior Casual Leave (CL), On-Duty (OD), or Medical Leave (ML) are automatically badged and locked so faculty does not mark them absent.

3. **Prior Leave vs Uninformed Cut Triage Engine**:
   - Differentiates authorized leaves from unauthorized absences.
   - On-Duty (OD) and Medical Leave (ML) with AWS S3 / Google Cloud Storage proof attachment viewer.
   - Daily 4:30 PM automated absent reconciliation with simulated parent SMS/WhatsApp triggers.

4. **Student 360° Attendance & Leave Dossier**:
   - 8-Period Heatmap matrix across weeks and months.
   - Subject-wise percentage progress bars with minimum 75% threshold indicator.
   - Full chronological leave history audit trail.

5. **Ambient Academic Background Design**:
   - Obsidian dark background with subtle radial mesh gradient glow and geometric dot grid pattern.
